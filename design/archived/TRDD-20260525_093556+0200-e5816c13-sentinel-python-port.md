## User request

> "implement the sentinel scripts too: downloads_dev/github-monitoring/sentinel-main.zip"

`sentinel-main.zip` is `jpr5/sentinel` v1.3.0 — the deterministic Ruby
GitHub-Actions security scanner from Atai Barkai's supply-chain-attack
writeup (the same article that drove the Guardian work in TRDDs c0734bde /
2a34e0cd / 2700e67d). My earlier plan deferred "Sentinel CLI integration"
as out-of-scope; the user has now explicitly pulled it back in.

## Decisions (locked via AskUserQuestion 2026-05-25)

- **Approach: port all 32 checks to Python** (NOT vendor the Ruby gem, NOT
  cherry-pick). Rationale: the plugin is uv/Python-only; a Ruby runtime dep
  would break that convention. A faithful port gives the Guardian the full
  Sentinel surface with zero new runtime deps (stdlib + PyYAML, already a
  project dep).
- **Fix mode: scan + the 6 mechanical auto-fixers** (NOT scan-only). The
  6 deterministic fixers from `lib/auto_fix.rb` are ported; AI-fix, the PR
  bot, the web dashboard, the MCP server, and GitLab/Bitbucket platform
  scanning are OUT OF SCOPE (the Guardian guards one local GitHub repo).

## Architecture (Python package under scripts/)

```
scripts/
  sentinel_scan.py            # CLI: `scan` (default) + `fix` subcommands, exit 0/1/2
  sentinel/
    __init__.py               # VERSION = "1.3.0" (upstream tracked)
    finding.py                # Finding dataclass + SEVERITIES/SEVERITY_ORDER
    workflow.py               # YAML-aware Workflow (on:->True quirk handled)
    rule_engine.py            # RuleEngine: load registry, run, severity-sort
    policy.py                 # .sentinel-ci.yml policy engine
    scanner.py                # orchestrator (local) + missing-dependabot/zizmor synthetics
    local_client.py           # reads .github/workflows/*.{yml,yaml} + dependabot
    autofix.py                # 6 mechanical fixers + run_fix() entry  [Phase 3]
    sha_resolver.py           # tag -> SHA via `gh api`               [Phase 3, used by unpinned fix]
    rules/
      __init__.py             # auto-discovers + imports every rule module
      base.py                 # Rule ABC + registry (__init_subclass__) + finding() helper
      guard_patterns.py       # GuardPatterns mixin + SAFE_TRIGGERS/JOB_PROPERTIES/DANGEROUS_CONTEXTS
      <30 rule modules>.py    # one per Ruby lib/rules/*.rb
    formatters/{__init__,terminal,json,sarif}.py
```

Source of truth for the port:
`downloads_dev/github-monitoring/sentinel-extracted/sentinel-main/`
(gitignored scratch; do NOT commit it).

Two synthetic repo-level checks (`missing-dependabot`, `missing-zizmor`)
live in `scanner.py`, not in `rules/` — same as the Ruby original. So:
30 rule modules + 2 synthetic = 32 checks.

## FROZEN interface (rules code against this — do not change it)

`sentinel.rules.base.Rule`
- class attrs: `name: str`, `description: str`, `severity: str`
  ("critical"|"high"|"medium"|"low")
- `def check(self, workflow) -> list[Finding]`
- helper: `self.finding(workflow, *, line, code=None, message=None, fix=None) -> Finding`
  (code defaults to the stripped line content; message defaults to description)
- concrete subclasses self-register via `__init_subclass__` (auto-discovered)

`sentinel.rules.guard_patterns.GuardPatterns` (mixin; use `class Foo(Rule, GuardPatterns)`)
- `safe_trigger_only(workflow) -> bool`
- `guarded_by_safe_event(workflow, line_num) -> bool`
- `strip_inline_comment(line) -> str`
- module constants: `SAFE_TRIGGERS`, `JOB_PROPERTIES`, `DANGEROUS_CONTEXTS`

`sentinel.workflow.Workflow`
- attrs: `filename`, `raw`, `raw_lines` (keepends), `data`
- `triggers()`, `jobs()`, `steps(job)`, `permissions(scope="workflow"|"job", job=None)`,
  `env(scope="workflow"|"step", step=None)`, `line_of(pat)`, `lines_of(pat)`,
  `line_content(num)`, `uses_actions()`, `run_blocks()`, `parse_error()`

`sentinel.finding.Finding(rule, severity, file, line, code=None, message=None, fix=None)`
- `.to_dict()`, sorts by severity rank.

## Porting contract (Ruby -> Python idioms — apply uniformly)

| Ruby | Python |
|---|---|
| `def name = "x"` | class attr `name = "x"` |
| symbol `:high` | string `"high"` |
| `Regexp.union(a,b,c)` | `re.compile("\|".join([a_src, b_src, c_src]))` (alternation, no extra anchors) |
| `/x/i` | `re.compile("x", re.IGNORECASE)` |
| `str.match?(re)` | `bool(rx.search(str))` |
| `str =~ re` | `rx.search(str)` |
| `str[/re/]` | `(m.group(0) if (m := rx.search(str)) else None)` |
| `str[/re/, 1]` | `m.group(1)` |
| `str.scan(re)` | `rx.findall(str)` |
| `str.gsub(re, r)` | `rx.sub(r, str)` |
| `arr.each_with_index{\|x,i\|}` | `for i, x in enumerate(arr)` |
| `n.downto(m)` | `range(n, m-1, -1)` |
| `val&.strip` | `val.strip() if val else None` |
| `hash.to_s` (for regex scan of env) | `str(hash)` |
| `step["run"]` | `step.get("run")` (guard `isinstance(step, dict)`) |
| `\A ... \z` | `\A ... \Z` |
| `^`/`$` (Ruby = line-anchored) | plain `^`/`$` when matching ONE `raw_lines` element; add `re.MULTILINE` when matching a multi-line `run:` block string |

Imports in each rule module:
`from sentinel.rules.base import Rule`
`from sentinel.rules.guard_patterns import GuardPatterns, DANGEROUS_CONTEXTS` (as needed)
`from sentinel.finding import Finding` (only if constructing Finding directly)

Ruby `private` methods -> Python methods prefixed `_`.
Module filename mirrors the Ruby filename (snake_case): `lib/rules/unpinned_actions.rb` -> `scripts/sentinel/rules/unpinned_actions.py`.
