# Project dictionary for cspell (SPELL_CSPELL in .mega-linter.yml).
#
# WHY THIS FILE EXISTS: cspell was enabled in .mega-linter.yml with NO dictionary
# at all. Because VALIDATE_ALL_CODEBASE is false, main only ever linted the few
# files a release commit touched, so the gap stayed invisible — while every PR
# that touched a workflow failed Lint on ordinary project vocabulary (zizmor,
# sarif, pinact, wagoid...). That is what blocked dependabot PRs #21/#22/#23/#25.
#
# These are REAL words of this project's domain: tool names, CLI flags, k8s/CI
# nouns, author surnames, and identifiers that appear in the security-scanning
# skills. Deliberate misspellings used as teaching examples are NOT here — they
# carry an inline `cspell:ignore` at their own site, so a genuine typo of the
# same word elsewhere still fails the build.
#
# One word per line. Regenerate with:
#   git ls-files | <filter> | xargs npx cspell --words-only --unique | sort -uf
